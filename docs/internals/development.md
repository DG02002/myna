# Local development

## First checkout

Use the Node.js version in [`.node-version`](../../.node-version) and pnpm 12.
Update pnpm with:

```sh
pnpm self-update
```

Install from the repository root:

```sh
pnpm install --frozen-lockfile
```

## Run the app

```sh
pnpm dev
```

The Vite dev server runs the app on the local Worker environment
(workerd) at `http://localhost:3000`.

## Quality gates

Run all repository gates before handing off code changes:

```sh
pnpm check
pnpm build
```

`pnpm check` chains formatting (`fmt:check`), lint (`oxlint`, type-aware),
markdown lint, type generation (`cf-typegen`) plus `tsc`, and unused-code
detection in both default and production modes (knip). `pnpm build` produces
build output without deploying it.

Use targeted checks while iterating: `pnpm run lint`, `pnpm run typecheck`,
`pnpm run fmt`.

`pnpm test` runs the media proxy suite inside the Workers runtime
(`@cloudflare/vitest-plugin`, configured in `vitest.config.ts` with a mock
upstream worker as the outbound service) and the Node-based engine tests.
The vitest pool auto-injects `nodejs_compat`, so green tests do not prove
the flag is present in `wrangler.jsonc` — check it separately when touching
Node built-ins.

## Generated and vendored code

- `worker-configuration.d.ts` — generated by `wrangler types` (`pnpm run
  cf-typegen`), gitignored, regenerated inside `check`. Never hand-write
  `Env`; bindings types come from this file.
- `src/routeTree.gen.ts` — generated by the TanStack Router CLI (`pnpm run
  generate-routes`), excluded from lint and formatting.
- `src/components/ui/` — generated shadcn primitives, read-only. Delete
  wholly-unused components; the CLI can restore them.
- `tools/oxlint/anti-slop/` — vendored lint plugin, never edit or reformat.
- `.repos/effect` — vendored read-only Effect reference. Sync with
  `pnpm run sync:repos`. Read `.repos/effect/LLMS.md` before writing Effect
  code.

## Authoritative library references

Mediabunny ships no agent skill; its docs are the source of truth and must be
read before writing code against it — never code Mediabunny from memory:

- <https://mediabunny.dev/llms.txt> — doc index
- <https://mediabunny.dev/llms-full.txt> — full guide
- <https://mediabunny.dev/mediabunny.d.ts> — shipped TypeScript definitions

Video.js 10 ships version-matched docs inside the installed packages at
`node_modules/@videojs/*/docs/llms.txt`; the `videojs` agent skill
(`.agents/skills/videojs`) indexes them.

## Deployment

```sh
pnpm run deploy
```

Deploys the built Worker to Cloudflare. Do not deploy as a verification step
for code changes; CI or the maintainer owns production deploys.

## Dependency policy

`pnpm-workspace.yaml` enforces a build-script allowlist, blocks exotic
subdependencies, and prefers releases at least 7 days old
(`minimumReleaseAge`). TanStack packages are pinned to exact versions because
they publish near-daily; bump them deliberately, together, and re-run the full
gate.
